# LINE公式のリッチメニュー設計｜予約と営業案内を迷わず選べる配置

公式LINEを運用しているにもかかわらず、「友だち登録してもらっても問い合わせにつながらない」という悩みを持つ経営者・担当者は少なくありません。その原因の多くは、メッセージ内容よりもリッチメニューの設計にあります。

リッチメニューはLINEアプリの画面下部に常時表示されるメニューで、ユーザーがトーク画面を開いた瞬間から目に入る、いわばお店の「入口」です。ここが整理されていないと、予約したいお客様も、営業時間を知りたいお客様も、どこをタップすればいいかわからず離脱してしまいます。

この記事では、中小企業が公式LINEのリッチメニューを設計するうえで押さえておきたい考え方と、予約・営業案内を迷わず選べる具体的な配置のポイントをお伝えします。

---

## リッチメニューの役割を正しく理解する

リッチメニューは「ナビゲーション」です。ホームページで言えば、グローバルナビゲーションやサイドバーのリンクに相当します。ユーザーがトーク画面にきたとき、次に何をすべきかを迷わず案内するのが役割です。

よくある失敗は、リッチメニューを「広告スペース」として使ってしまうことです。バナー画像を貼り付けて終わり、という設計では、ユーザーはどこをタップすればいいのかわかりません。

また、ボタンが多すぎるのも問題です。LINEのリッチメニューは最大6マスまでボタンを設置できますが、すべてを埋めればよいわけではありません。選択肢が多いほど人は迷います。業種にもよりますが、まず3〜4項目に絞り込んで設計することをおすすめします。

**リッチメニューを設計する前に確認したいこと**

- 公式LINEに来るユーザーが一番よくする行動は何か
- 問い合わせ・予約・来店につながる動線はどこか
- 電話・フォーム・LINEのどこで予約を受けているか
- 営業時間・定休日の問い合わせはどのくらいあるか

この4点を整理するだけで、リッチメニューに入れるべき項目の優先順位が見えてきます。

## 予約と営業案内を「迷わず選べる」配置の原則

ユーザーがリッチメニューを見て「どこをタップすれば予約できるんだろう」と0.5秒でも迷ったら、すでに設計として改善の余地があります。迷わせないためには、以下の3つの原則を意識してください。

### 原則1：最重要ボタンを左上または左下に置く

人の視線は左から右、上から下に流れます。LINEのリッチメニューを2段（上下）に分けた場合、最初に目が行くのは左上です。予約ボタンや問い合わせボタンなど、最もアクションにつなげたいものをここに配置します。

1段レイアウトの場合は左端が先に目に入ります。業種によって「予約」と「問い合わせ」どちらが最重要かは変わりますが、どちらか一方を最も目立つ場所に固定する、という考え方は共通です。

### 原則2：営業案内は「迷ったときに確認する場所」として独立させる

「営業時間は何時まで？」「定休日はいつ？」という質問は、問い合わせの中でも特に頻度が高いものです。これを個別のボタンとして用意しておくと、ユーザーは電話することなく自己解決できます。

タップ後に遷移させる先は、外部の予約サイトではなくLINEのリッチメッセージや固定テキストで営業情報を表示する設計が使いやすいです。ユーザーがLINEアプリを離れずに情報を得られるため、離脱率が下がります。

### 原則3：ラベルは動詞+目的語で書く

ボタンのラベルが「お知らせ」「詳細はこちら」だけでは、ユーザーはタップする前に何が起きるかわかりません。「予約する」「営業時間を見る」「スタッフに相談する」のように、動詞と目的語をセットで書くことで、タップ後のアクションが明確になります。

## 業種別・リッチメニュー配置パターン例

リッチメニューに正解は一つではありませんが、業種ごとによく機能するパターンがあります。

### 飲食店・美容室・整体院（予約が中心の業種）

```
[予約する]　　　[営業時間・定休日]
[メニューを見る]　[スタッフに聞く]
```

左上に予約ボタンを固定し、次によく聞かれる「営業時間・定休日」を右上に。メニュー閲覧はその次の優先度で配置します。

### 士業・コンサル・リフォーム会社（相談がファーストステップの業種）

```
[無料相談を申し込む]　[よくある質問]
[サービス内容を見る]　[費用について]　[事例を見る]
```

問い合わせへのハードルを下げるために「無料相談」を最上位に。次に「よくある質問」でユーザーの不安を解消する動線を作ります。

### 小売店・EC（商品誘導が中心の業種）

```
[商品を見る]　[キャンペーン情報]
[店舗情報・地図]　[お問い合わせ]
```

購買行動に直結する「商品を見る」を最上位に置き、来店を促す「店舗情報・地図」を配置します。

これらはあくまで参考パターンです。実際には自社のユーザー行動を分析したうえで調整してください。

## 設計後に確認すべきチェックポイント

リッチメニューを公開する前に、以下の項目を必ず確認してください。

**ビジュアル面**
- ボタンのラベルが小さすぎてスマートフォンで読みにくくないか
- 背景画像とテキストのコントラストが確保されているか
- タップ可能な領域が指で触れやすいサイズになっているか（最低でも44×44px相当の体感面積）

**動線面**
- 各ボタンをタップしたときに正しいURLまたはアクションが発動するか
- 外部リンクに遷移する場合、スマートフォン表示で崩れていないか
- 予約ページや問い合わせフォームがモバイル対応されているか

**運用面**
- 季節・キャンペーンに合わせてリッチメニューを変更する運用フローがあるか
- LINEの管理画面にアクセスできる担当者が明確になっているか

特に「スマートフォンで実際にタップして確認する」ことは必須です。PCのプレビューでは気づかないズレやリンク切れが、実機確認で見つかることは珍しくありません。

## まとめ｜リッチメニューは「お客様を迷わせない設計」が基本

公式LINEのリッチメニューは、登録してくれたユーザーを予約・問い合わせにつなげる最初の接点です。見た目のデザインよりも、**「誰が・何をしたいときに・どこをタップすれば解決するか」** を軸に設計することが、実際の行動変容につながります。

今回お伝えしたポイントを整理すると、

1. 最重要アクション（予約・相談）を左上または目立つ位置に固定する
2. 営業案内は独立したボタンで自己解決を促す
3. ラベルは「動詞+目的語」で迷いを排除する
4. 公開前にスマートフォン実機でタップして確認する

という4点です。

「リッチメニューを作ったけど反応が薄い」「そもそも何を入れればいいかわからない」という場合は、まず現状の設計を第三者の目で見直すことから始めるのが効果的です。

株式会社サイプレスでは、公式LINEの運用設計から具体的なリッチメニューの構築支援まで、中小企業の実情に合わせた形でご相談をお受けしています。「今の設計で合っているか確認したい」という段階からでもお気軽にお問い合わせください。
