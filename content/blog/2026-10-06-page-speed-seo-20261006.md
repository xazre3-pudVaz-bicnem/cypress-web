# ページ速度がSEOに与える影響：Lighthouseスコアを90点以上に改善する方法

「ホームページのデザインは整えたのに、なぜか検索順位が上がらない」——そんな悩みを抱える中小企業の担当者の方は少なくありません。原因のひとつとして見落とされがちなのが、**ページの表示速度**です。

Googleは2021年以降、Core Web Vitalsをランキング要因として正式に組み込んでいます。つまり、いくらコンテンツが充実していても、ページの読み込みが遅ければSEO的に不利な状況に置かれる可能性があります。

この記事では、Googleが提供する無料の診断ツール「Lighthouse」を使ってページ速度を数値で把握し、スコアを90点以上に引き上げるための具体的な改善手順を解説します。

---

## ページ速度とSEOの関係を正しく理解する

まず前提として、ページ速度は「ランキングに直接影響する要因のひとつ」ですが、コンテンツの質や被リンクなどと比べると、単体での影響力は限定的です。ただし、速度が著しく遅いサイトは**クロール効率の低下**や**直帰率の上昇**にもつながるため、間接的なSEOへの悪影響が積み重なっていくという点を理解しておく必要があります。

特にモバイル環境での表示速度は重要です。Googleはモバイルファーストインデックスを採用しているため、スマートフォンでの読み込み速度がデスクトップ以上に評価に影響します。「スマホで見るとなぜか重い」という状態のサイトは、見た目の問題だけでなく検索評価にも影響が出ていることがあります。

---

## LighthouseとCore Web Vitalsの読み方

Lighthouseは、ChromeブラウザのDevTools（開発者ツール）から無料で使えるページ診断ツールです。スコアは0〜100点で評価され、**90点以上がGreen（良好）**、50〜89点がOrange（改善の余地あり）、49点以下がRed（要対応）と分類されます。

Lighthouseのパフォーマンス項目は、主に以下のCore Web Vitalsと関連しています。

| 指標 | 正式名称 | 意味 | 良好の基準 |
|------|----------|------|------------|
| LCP | Largest Contentful Paint | 最大コンテンツの表示速度 | 2.5秒以内 |
| FID / INP | Interaction to Next Paint | 操作への反応速度 | 200ms以内 |
| CLS | Cumulative Layout Shift | レイアウトのズレ | 0.1以下 |

診断の手順は以下のとおりです。

1. ChromeでサイトのURLを開く
2. F12キー（またはCmd+Option+I）で開発者ツールを起動
3. 上部タブから「Lighthouse」を選択
4. 「モバイル」を選択し「分析を実行」をクリック
5. 数分後にスコアと改善項目が表示される

PageSpeed Insights（https://pagespeed.web.dev/）でも同様の診断が可能で、こちらはURLを入力するだけで使えるため、非エンジニアの担当者にも扱いやすいツールです。

## スコア90点以上を目指す：具体的な改善施策

### 1. 画像の最適化（効果が出やすい最優先項目）

多くのサイトでスコアを大きく引き下げているのが、**最適化されていない画像**です。一眼カメラで撮影したまま、あるいはデザイナーから受け取ったまま圧縮なしにアップロードしているケースは非常に多く見られます。

対策としては以下を実施してください。

- **WebP形式への変換**：JPEGやPNGより圧縮率が高く、ファイルサイズを大幅に削減できる
- **適切なサイズへのリサイズ**：表示サイズが300pxの場所に1500pxの画像を使わない
- **遅延読み込み（Lazy Load）の設定**：スクロールしないと見えない画像はloading="lazy"属性を付与する

WordPressを使用している場合、「Smush」や「ShortPixel」などのプラグインで自動的に最適化する運用が現実的です。

### 2. キャッシュとサーバーレスポンスの改善

ページを初めて読み込んだ際のデータをブラウザに保存（キャッシュ）しておくことで、2回目以降のアクセスを高速化できます。WordPressであれば「W3 Total Cache」「WP Super Cache」といったプラグインで設定できます。

また、**サーバー自体のレスポンス時間（TTFB：Time to First Byte）**が遅い場合は、プラグインの最適化だけでは限界があります。共有レンタルサーバーでスコアが伸び悩む場合は、上位プランへの変更やVPSへの移行を検討する価値があります。

### 3. CSSとJavaScriptの最適化

ページを表示するまでに不要なCSS・JavaScriptが読み込まれていると、それだけ表示が遅くなります。

**レンダリングブロッキングリソースの除去**が代表的な対策で、具体的には以下を行います。

- 使っていないCSSルールの削除（未使用CSSの除去）
- JavaScriptの読み込みをbody閉じタグ直前に移動、またはdefer属性の付与
- CSSとJSファイルの圧縮（ミニファイ）

WordPressの場合、「Autoptimize」などのプラグインがこれらをある程度自動化してくれますが、設定を誤るとレイアウト崩れが起きることがあるため、変更前にバックアップを取る習慣をつけてください。

### 4. CLSを下げる：レイアウトのズレを防ぐ

CLSは、ページを開いた後に画像や広告が突然ズレる現象を数値化したものです。スコアが高いサイトは「読み込み途中にボタンの位置がずれてクリックミスする」といった体験をユーザーに与えています。

主な原因と対策は以下のとおりです。

- **画像にwidth・height属性を明示する**：ブラウザが事前に表示領域を確保できるようになる
- **Webフォントの読み込み方法を見直す**：font-display: swapを使い、フォント切り替え時のズレを最小化する
- **広告やバナーのサイズを事前に確保する**：コンテンツの上に突然挿入されないよう余白を設ける

## 改善後の確認と継続的なモニタリング

一度改善したからといって、その状態が永続するわけではありません。プラグインのアップデートやコンテンツの追加によって、スコアが下がることは日常的に起こります。

定期的なモニタリングには以下のツールが有効です。

- **Google Search Console**：Core Web Vitalsレポートから実際のユーザーデータを確認できる
- **PageSpeed Insights**：月に1回以上、主要ページをチェックする習慣をつける
- **CrUX（Chrome User Experience Report）**：実際のChromeユーザーの体験データを集計している

特にGoogle Search ConsoleのCore Web Vitalsレポートは、ラボデータ（ツール上のシミュレーション）ではなく実際のユーザーデータ（フィールドデータ）を反映しているため、SEO評価に直結する数値として重視すべきです。

---

## まとめ：ページ速度改善は「一度やれば終わり」ではない

ページ速度の改善は、効果が出るまでに時間がかかる地道な取り組みです。しかし、Lighthouseで現状を数値で把握し、画像最適化・キャッシュ設定・JS/CSS最適化・CLSの修正という優先度の高い施策から順に対応することで、スコアは着実に改善していきます。

「何から手をつければいいかわからない」「社内にエンジニアがいない」という場合、ツールの使い方から具体的な改善施策まで、専門家のサポートを活用するのもひとつの現実的な選択肢です。

株式会社サイプレスでは、ページ速度の診断からCore Web Vitalsの改善、SEO対策の全体設計まで、中小企業の実情に合わせた支援を行っています。「まず現状を把握したい」という段階からでも、お気軽にご相談ください。
